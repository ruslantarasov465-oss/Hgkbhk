# 🚀 Быстрый старт

Этот гайд поможет вам начать работу с аналитическим инструментом за 5 минут.

## Шаг 1: Установка

```bash
# Установите зависимости
pip install -r requirements.txt
```

## Шаг 2: Подготовка данных

Поместите ваш Excel файл в папку `data/input/`:

```bash
cp /path/to/your/monthly_data.xlsx data/input/
```

**Поддерживаемые форматы:**
- Excel (.xlsx, .xls)
- CSV (.csv)

**Структура данных:**
- Первая строка - заголовки колонок
- Колонка с названиями филиалов (например, "филиал", "branch")
- Колонки с планом (например, "GMV ПЛАН ДЕКАБРЬ")
- Колонки с фактом (например, "Факт ДЕКАБРЬ СС")
- Процентные показатели, расходы и т.д.

## Шаг 3: Запуск анализа

### Вариант 1: Простейший запуск

```bash
python src/main.py data/input/monthly_data.xlsx
```

### Вариант 2: Интерактивный режим

```bash
python src/main.py --interactive
```

Следуйте подсказкам на экране.

### Вариант 3: С параметрами

```bash
# Анализ конкретного листа Excel
python src/main.py data/input/monthly_data.xlsx --sheet "Декабрь"

# Без создания графиков (быстрее)
python src/main.py data/input/monthly_data.xlsx --no-charts

# Только анализ, без отчетов
python src/main.py data/input/monthly_data.xlsx --no-reports
```

## Шаг 4: Просмотр результатов

После завершения анализа найдете:

### 📄 Отчеты в папке `reports/`

- **HTML отчет** - откройте в браузере для интерактивного просмотра
- **Excel отчет** - структурированные данные с листами:
  - "Данные" - исходные данные
  - "Инсайты" - найденные проблемы и возможности
  - "Топ филиалов" - рейтинг
  - "Сводка" - статистика
- **Текстовый отчет** - краткая сводка для быстрого ознакомления

### 📊 Графики в папке `reports/charts/`

- `plan_vs_fact.png` - сравнение плана и факта
- `execution_percentage.png` - процент выполнения плана
- `top_branches.png` - рейтинг филиалов
- `insights_summary.png` - сводка по инсайтам

## Шаг 5: Интерпретация результатов

### Типы инсайтов:

🔴 **Критические** - требуют немедленного внимания
- Недовыполнение плана > 25%
- Серьезные аномалии

⚠️ **Предупреждения** - требуют мониторинга
- Отклонения от плана 15-25%
- Низкая эффективность

✅ **Положительные** - лучшие практики
- Превышение плана
- Высокий рост
- Высокая эффективность

ℹ️ **Информационные** - общая статистика
- Топ-исполнители
- Средние показатели
- Распределение

## Примеры использования в коде

### Базовый анализ:

```python
from src.main import AnalyticsTool

tool = AnalyticsTool()
results = tool.analyze_file('data/input/monthly_data.xlsx')

# Просмотр инсайтов
for insight in results['insights']:
    print(f"{insight['severity']}: {insight['title']}")
```

### Получение только критических проблем:

```python
critical = [i for i in results['insights'] if i['severity'] == 'critical']
print(f"Найдено {len(critical)} критических проблем")
```

## Настройка под ваши нужды

Отредактируйте `config.yaml`:

```yaml
insights:
  plan_deviation_threshold: 15  # Измените порог отклонения
  critical_deviation: 25        # Измените критический порог
  top_n: 10                     # Количество топ филиалов

reports:
  format: ["html", "excel"]     # Выберите нужные форматы
```

## Решение типовых проблем

### Ошибка: "File not found"
```bash
# Проверьте путь к файлу
ls data/input/

# Используйте полный путь
python src/main.py /full/path/to/file.xlsx
```

### Ошибка: "No module named 'openpyxl'"
```bash
pip install openpyxl
```

### Данные не распознаются
- Убедитесь, что первая строка содержит заголовки
- Проверьте, что колонки содержат данные (не пустые)
- Для CSV убедитесь в правильной кодировке (UTF-8)
